An HR app for Magppie's office, showroom, factory and site staff. It currently runs on invented sample data; the database design is written but not yet switched on.

3. New: location + face check on attendance

Clock In, Clock Out and Punch now save only after both checks:

  1. Exact location — the phone's GPS (high accuracy, never a cached reading). No location, no punch.
  2. Face check — a selfie must match the face the employee registered once (the first time they clock in, or from Me → Face for attendance, with a consent checkbox). A different face is blocked.

If the person is farther from their site than allowed (default 200 m), the punch is saved but flagged for the manager, never blocked, because installers clock in at client sites. HR records each site's position by standing there and tapping "use my location" (Settings → Attendance sites). Each punch keeps the location, its accuracy, the distance from the site, the match score and a small selfie for review.

Face matching runs entirely on the phone (open-source face-api library); no photo is sent to any server in this version.

Before using this with real staff (details in docs/13, questions 28–33):
  • Biometric data (DPDP Act): consent wording, how long face data is kept, who can delete it, and where it is stored need an HR/legal decision.
  • Liveness: a printed photo or a phone screen held up to the camera could pass. Add a blink/turn-head check before go-live.
  • Strictness and distance: the face-match limit (0.5) and the 200 m radius are starting values, not yet tuned on real phones and staff.
  • Staff without a camera or GPS currently cannot clock in, so a fallback is needed.
  • Who reviews flagged punches, and whether a manager can reject one.

4. New look

Changed from brown and beige to white with sky blue: white sidebar and header, a sky-blue active menu item, a sky-blue welcome banner on Home, rounded cards with soft shadows, and pill-shaped buttons. All text colours were checked for readability (WCAG AA contrast).

5. How to run it

git clone https://github.com/jiyasiwach/magppie-hr-app.git
cd magppie-hr-app
git checkout verified-punch-and-sky-theme   # this round's work (local branch until pushed)
npm install
npm run dev -- -p 3040                       # then open http://localhost:3040

Use the "Viewing as" switcher (top right) to see the Employee, Manager and HR views. To try the camera feature, open the app in Chrome or Safari and allow location and camera when asked. On a phone it needs HTTPS (the deployed site), because browsers only allow camera and GPS on secure pages.

6. What is deliberately not real yet

  • All 40 employees and their records are invented, and changes reset when the page reloads.
  • No file storage: documents are records, and "Download" explains there is nothing behind it.
  • Salary and Expenses show "not configured". There is no payroll.
  • The feedback form says plainly that nothing was sent.
  • The product name is not chosen. The app shows [APP_NAME] (a one-line change).
